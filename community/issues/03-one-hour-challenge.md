# Start here: one-hour Context Compiler challenge / 一小时入门挑战

You do not need to commit to the whole project. Pick **one** small track and leave the result in this Issue.

## Track A — find one context bypass

Using the current OpenCode source, identify one input that could still reach the provider request after a naive Context Compiler claims to have isolated execution.

Deliver only:

- the exact file and function;
- the bypassed input (instructions, skills, tools, MCP, history, tool result, or another source);
- one minimal trace or test idea that would expose it.

## Track B — design one falsification task

Contribute one realistic Chinese coding-agent task where using the wrong context leads to a plausible but wrong result.

Deliver only:

- the user task;
- one critical fact and one distractor;
- a machine-checkable success condition;
- the failure that would falsify the compiler.

## Acceptance

- reproducible and specific;
- small enough to review independently;
- no requirement to implement the full compiler;
- no payment, equity, IP, or long-term commitment is implied.

A strong submission earns an invitation to the frozen Runtime or Eval milestone. A counterexample that shows the product should not be built is also a successful contribution.

Project brief and evidence boundary: <https://feiai2026.github.io/aios-context-compiler/>

## 中文说明

任选一个方向即可：找出一个 OpenCode 上下文绕过点，或者设计一个最可能推翻上下文编译器的真实中文任务。第一步控制在 60–90 分钟内，重点看证据是否具体、可复现、可独立验收，不要求先承诺长期合作。
